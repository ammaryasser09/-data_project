# Realistic Egyptian test set

`realistic_test_egyptian.csv` — 200 questions in the way callers talk: code-switching
("الـ check in"), typos, relative dates ("من الحد الجاي"), spoken digits ("بي زيرو واحد…"),
missing details, several requests at once, anger, emergencies, and things the KB does not say.

| Column | Meaning |
|---|---|
| route | RAG, DATABASE, TOOL, ACTION, CLARIFY, REFUSE, ESCALATE, EMERGENCY (combinations with +) |
| expected_doc | KB file(s) with the answer, `;`-separated |
| expected_tool | tool from `09_Application/rag/tools.py` |
| expected_facts | what a correct answer contains; for bookings computed from the tables |
| must_not | what a correct answer must avoid (e.g. revealing a booking before the identity check) |
| tags | kb_gap, spoken_digits, relative_date, past_date, verification, safety, multi, … |

Generated by `06_Scripts/generation/realistic_test_v1.py` (rerun after SYSTEM_DATE moves).
Retrieval: `python3 -m 09_Application.rag.evaluate --realistic 05_Evaluation/realistic_test/realistic_test_egyptian.csv`.
End-to-end answers need an LLM judge or a human: check route, facts, must_not.
Written by an AI: add questions from real people before trusting the numbers fully.
